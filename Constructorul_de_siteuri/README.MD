**Constructorul de Site-uri — Programare web pentru copii curioși** este o carte practică adresată copiilor între 10 și 14 ani care vor să descopere lumea programării web de la zero. Prin metafore vii — internetul ca un sistem poștal, HTML ca scheletul unei case, CSS ca hainele și decorațiunile, iar JavaScript ca electricitatea care dă viață totului — conceptele tehnice devin accesibile și captivante. Fiecare capitol introduce noțiuni noi pas cu pas, cu explicații vizuale prin diagrame ASCII, exemple de cod pe care cititorii le pot încerca imediat și casete colorate cu sfaturi, avertismente și curiozități din industria tech.

Cartea este organizată în patru părți care urmează o progresie naturală: de la fundamentele HTML și CSS (structură, stilizare, layout cu Flexbox și design responsive), trecând prin JavaScript (variabile, funcții, decizii, bucle, manipularea DOM-ului și evenimente), până la animații profesionale cu CSS și JavaScript. Fiecare capitol se încheie cu o secțiune de greșeli frecvente, un mini-quiz cu răspunsuri și fapte surprinzătoare din istoria tehnologiei, asigurând atât consolidarea cunoștințelor, cât și menținerea entuziasmului.

Partea cea mai valoroasă a cărții o constituie cele trei proiecte majore pe care tinerii programatori le construiesc integral: un Quiz Game interactiv cu scor live și feedback vizual, un joc 2D pe Canvas numit Catch the Stars cu stele care cad, bombe, niveluri progresive și detecție a coliziunilor, și un portofoliu web personal complet cu design responsive, animații la scroll, bare de competențe animate și formular de contact cu validare. Aceste proiecte transformă teoria în practică și oferă copiilor lucruri concrete de care pot fi mândri.

Cartea se încheie cu un ghid al pașilor următori: cele patru drumuri pe care un tânăr programator le poate urma (Frontend, Backend, Mobile sau Game Development), resurse gratuite de calitate, sfaturi pentru dezvoltare continuă și instrucțiuni pentru publicarea portofoliului online. Mai mult decât o simplă introducere în programare, *Constructorul de Site-uri* cultivă gândirea logică, creativitatea și încrederea — oferind copiilor curioși instrumentele cu care pot construi, literalmente, viitorul.
